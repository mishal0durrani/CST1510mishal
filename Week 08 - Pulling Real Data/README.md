# Week 8: Get your own data from an API

**This week your project gains:** `fetch_data.py`, a few small functions that ask an API for data and save it as `DATA/raw.csv`.

```
CST1510_CW2/        (your GitHub repository)
  fetch_data.py
  DATA/raw.csv
```

This is where the project starts: students create the `CST1510_CW2` repository. Every later week adds to it and commits.

---

## Workshop

| Do |
|---|
| **Demo:** run `DEMO/project/fetch_data.py`: live earthquakes become `raw.csv` in one step |
| Topic: `01 - Calling a Web API/` (GET requests, status codes, `.json()`, handling errors) |
| Topic: `02 - Reading Files from the Web/` (nested JSON and tidying a table with pandas) |
| Optional extra: `03 - Light Regex/` (patterns for messy text) |
| Optional extra: `04 - From Functions to a Class/` (the same code as a class; the lab itself uses plain functions) |

## Lab

Everything is in `LAB/W08_Lab.ipynb`: choose an API, make the request, find the records, make a table, tidy it, then build `fetch_data.py`.
